Labeled scan corpus: one comment group per case. Headers: `=== ai`, `=== human`, or
`=== protected <class>`. Human cases include the phrasings people really use, so the
precision numbers are not flattered. See packages/core/test/scan.corpus.test.ts.
The later human cases in each file are modeled on patterns measured in CPython's stdlib
and ESLint's lib (design.md § Scan detectors): people restate code, number steps, and
write "Note that" and "Ensure that" too.
