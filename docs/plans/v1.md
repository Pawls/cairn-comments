### A12 — Markerless round trip, Python · Opus 5.5 / high {#a12}

**Status:** Done 2026-09-25, not yet struck: the owner has not tried it by hand. 365
tests pass on Windows and in WSL Ubuntu (git 2.43, Node 26); lint clean. Rules, the
metadata keys, and the rejected approaches are in design.md § Anchoring. The kill
criterion did not fire: decorators, class members, duplicate names, and comments inside
argument lists all round-trip; only formatter-joined lines fail to place (§ Known gaps).

Visible change: after `init --markerless`, every blob and the owner's checkout are the
code with AI comments removed, byte for byte. An agent worktree shows each comment where
it was written. Moving a function, editing a different function, or reformatting the file
does not lose or misplace a comment.

- [x] design.md: new § Anchoring and the Decisions row "Anchoring" rewritten, with the
      adoption reason and the rejected fuzzy placement.
- [x] `core` (`placement.ts`): the anchor per comment is `pos`, `scope` (not `decl`),
      `body`, `node` and `nth` (the node's hash and which match in its scope, in place of
      a statement path: formatter wrapping cannot shift it), `skip`, `seq`, `indent`,
      `gap`, `eof`. `at` was not used: provenance already uses it for the timestamp.
- [x] `core`: `stripComments` removes sigil comments whole, keeps every other terminator,
      and is pure and idempotent.
- [x] `core`: `placeComments` inserts every entry whose scope resolves, whose node is
      found, and whose function (if any) hashes to `body`; property
      `placeComments(stripComments(sync(x))) == sync(x)` over 300 generated files (5,000
      once). Entries that do not match are kept and returned as `unplaced`.
- [x] Ids live in the sidecar and in agent worktrees only; `stripComments` removes them.
- [x] Comment-only edits: the post-edit `sync` writes the sidecar and `git add` stages it.
      `commit -am` alone cannot carry them: git judges a commit empty before the
      pre-commit hook stages anything (design.md § Anchoring). `sync --staged` also takes
      every file still holding a sigil.
- [x] Deleted vs. unplaced: a per-worktree seen record under the git dir, written by
      smudge and every tool rewrite. Re-running placement was rejected: a cherry-pick,
      `reset`, or `restore` adds sidecar entries without rewriting the source, and they
      would have read as deleted.
- [x] `cli`: `sync`, `expand`, `collapse`, `init --markerless`, and the filter endpoints
      on the new model, plus `refresh` and the `post-checkout`, `post-merge`,
      `post-commit`, `post-rewrite` hooks that run it (a cherry-pick of a comment-only
      commit rewrites no source). `check` reports only sigil comments in blobs.
- [x] Integration (`markerless.test.ts`, `Sandbox`, both `autocrlf`, process and
      one-shot): the A1 scenarios ported, plus the owner moving a function, editing a
      sibling, and reformatting a call; an owner edit inside a function hides its
      comments without deleting them; deleting a comment deletes its entry. The Python
      A7 formatter pairs run in `placement.test.ts`.
- [x] Verify: `npm test` 365 passed and `npm run lint` clean, on Windows and in WSL.
- [ ] Owner's hand test: `init --markerless` in a scratch repo, an agent worktree, a
      comment-only commit, a merge into the owner's checkout.

Kill criteria: if some Python comment positions cannot round-trip exactly (between
decorators, inside argument lists or collection literals), restrict sigil comments to
statement positions, have `tag` leave the others untagged, and list the refused positions
in design.md.
