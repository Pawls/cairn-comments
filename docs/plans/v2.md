# v2 plan: Cairn Comments

Rebrand Slopstash to **Cairn Comments** and open it to humans: private notes that never
ship, alongside the AI comment features. Then add cached function summaries that let
agents skip reading unchanged code. Work starts after v1 lands. Decisions behind this plan
are recorded in the "Settled" section; settled rules move into design.md as slices ship.

## Settled

- **Name.** Display name "Cairn Comments", package and extension id `cairn-comments`, CLI
  `cairn`. "cAIrn" is a logo treatment only. Two small Marketplace extensions already use
  "Cairn" (`valpet.cairn-extension`, 82 installs, AI task context; `fractaldecoder.cairn`,
  9 installs, Rust snapshots), so the bare name is not used for the listing.
- **No task graph.** Context keeping in the style of beads (and `valpet.cairn-extension`)
  is out of scope: it stores work state, not knowledge anchored to code.
- **Never hide code on disk.** Summaries steer agents at the tool layer (outline command,
  read hook). Eliding bodies through the filter breaks builds, tests, grep, and LSP, makes
  `clean` impure, and invites agents to reimplement the stub.
- **Summaries guide navigation; source guides edits.** An agent reads a function's source
  before changing it.

## Slice 2: Private mode design · opus / high

Zero-trace notes for repos that forbid scattered comments: no marker and no sidecar in
anything pushed.

- [ ] Design section in design.md: `clean` strips the whole comment; sidecars live under
      `.git/`; driver config in `.git/config`, attributes in `.git/info/attributes`
- [ ] Marker-free anchoring: symbol path plus statement hash (already stored per entry),
      with fuzzy fallback on surrounding lines
- [ ] Orphan handling when a teammate's change removes or moves the anchor: list, never drop
- [ ] Confirm `clean` stays pure in (path, source)
